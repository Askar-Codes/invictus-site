Behind the Scenes

Every line on this site was typed by hand, no drag-and-drop builders, no templates downloaded from somewhere else. I kept the editor of choice to JetBrains WebStorm for the whole project, mostly because of its autocomplete and instant error highlighting - both saved me from a lot of typos while working through four pages. Since all four pages share the same header, nav, main, and footer skeleton, I built that structure once on the home page and then copied it over, swapping in new content each time.

Keeping the Formatting structure

Before checking each file, I reformatted it with WebStorm's built-in shortcut: 

Ctrl+Alt+L

That alone fixed most of the spacing issues without me having to hunt for them manually.

Checking the Markup

Rather than trust that the HTML was correct just because it looked fine in the browser, I ran each file through the W3C Markup Validation Service by uploading it directly, one page at a time. A clean file returns something along these lines: 

Document checking completed. No errors or warnings to show.

The first pass on pricing.html actually came back with three errors - spaces inside the image file names in the src attribute, which the validator flags as an illegal character in a path segment. Renaming the files to use hyphens instead of spaces (for example, technogym-equipment.png) fixed it.
